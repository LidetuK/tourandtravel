# Mesfin Shumet Tour and Travel (Next.js)

Next.js App Router port of the Mesfin Shumet Travosy PHP site. Look and content preserved for the live Mesfin pages.

## Run locally

```bash
cd mesfin-next
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` Home
- `/tours` Tours list
- `/tours/[slug]` Tour detail (e.g. `/tours/mount-entoto-viewpoint-tour`)
- `/destinations` `/trips` `/deals` `/groups`
- `/about` `/blog` `/contact` `/login`

PHP site in `../Travosy` remains the original reference.
